
# SmartCity EcoSystem

### Plataforma local de monitoreo y sostenibilidad para ciudades inteligentes

## Descripción del proyecto

SmartCity EcoSystem es un prototipo de aplicación web desarrollado como propuesta tecnológica para mejorar la gestión de recursos en una ciudad inteligente.

El proyecto busca representar cómo las tecnologías emergentes pueden contribuir a optimizar el consumo energético, analizar la movilidad urbana y mejorar la gestión de residuos.

La aplicación permite registrar información, consultar indicadores y calcular estimaciones de ahorro energético e impacto ambiental.

## Objetivo

Demostrar la aplicación de tecnologías relacionadas con los sistemas distribuidos y Green Computing mediante una herramienta web sencilla, funcional y de almacenamiento local.

## Tecnologías utilizadas

- **HTML5:** estructura de la aplicación.
- **CSS3:** diseño visual y adaptación a diferentes tamaños de pantalla.
- **JavaScript:** funcionalidades, cálculos y procesamiento de información.
- **LocalStorage:** almacenamiento de registros directamente en el navegador.

## Funcionalidades principales

### 1. Dashboard
- Visualización de indicadores generales.
- Resumen de ahorro energético.
- Estimación de emisiones de CO₂e evitadas.
- Consulta de registros recientes.

### 2. Gestión energética
- Registro de mediciones de consumo.
- Comparación entre consumo inicial y optimizado.
- Cálculo de ahorro energético.
- Estimación de emisiones de CO₂e evitadas.

### 3. Gestión de movilidad
- Registro de ubicaciones.
- Registro de cantidad de vehículos.
- Registro de distancias recorridas.

### 4. Gestión de residuos
- Registro de contenedores.
- Monitoreo simulado de niveles de llenado.
- Identificación de contenedores que requieren recolección prioritaria.

### 5. Sostenibilidad tecnológica
Presentación de cinco estrategias:
- Optimización energética.
- Edge Computing.
- Virtualización.
- Optimización de rutas.
- Uso eficiente de la nube.

### 6. Historial de registros
- Consulta de información registrada.
- Exportación de registros en formato CSV.
- Carga de datos de ejemplo.
- Eliminación de registros.

## Arquitectura conceptual

La propuesta tecnológica contempla cinco capas:

1. **Dispositivos IoT:** sensores de energía, movilidad y residuos.
2. **Edge Computing:** procesamiento y filtrado local de información.
3. **Comunicación:** transmisión de datos mediante MQTT y HTTPS.
4. **Servicios distribuidos:** microservicios, contenedores e inteligencia artificial.
5. **Almacenamiento y visualización:** bases de datos, servicios en la nube y dashboards.

El prototipo actual ejecuta localmente los cálculos y la gestión de información en el navegador. Las demás tecnologías forman parte de la arquitectura conceptual propuesta.

## Instalación y ejecución

No requiere instalaciones adicionales, servidores ni dependencias externas.

1. Descargar o clonar este repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `index.html` con un navegador web.
4. Utilizar los diferentes módulos de la aplicación.

## Almacenamiento de información

La aplicación utiliza LocalStorage para conservar los registros en el navegador.

Los datos se almacenan localmente y no se envían a servidores externos.

## Sostenibilidad ambiental

El proyecto busca demostrar cómo la optimización de recursos tecnológicos puede contribuir a:

- Reducir el consumo energético.
- Disminuir emisiones contaminantes.
- Aprovechar mejor los recursos computacionales.
- Optimizar los procesos urbanos.
- Promover el uso responsable de la tecnología.
